# LINEスタンプを作った後、どう広めて売るか — リサーチまとめ

インスタ投稿（リール／カルーセル）用のリサーチメモ。調査日: 2026-09-30

---

## 結論：一番売れるやり方

**「発売直後の初動を最大化 → ランキング・新着に乗せる → シリーズ化で積み上げる」**

LINEスタンプは、ストアの「新着」「ランキング」に載ると、そこから連鎖的に売れます。
SNSで宣伝する一番の目的は、**発売から数日間の購入と送信数を一気に集めてランキングに乗せること**です。

## 1. 売れる仕組みを知る（前提知識）

| ポイント | 内容 |
|---|---|
| ランキングの決まり方 | ダウンロード数・**送信数**・購入してから送信するまでの速さが効くと言われている。特に送信数が重要 |
| 初動 | 「新着クリエイターズスタンプ」の上位に長くいるほど、そこからさらに売れる |
| 取り分 | 1セット120円（50コイン）なら、LINEストア経由で約42円、アプリ内ショップ経由で約31円（約35%） |
| もう一つの収入源 | LINEスタンプ プレミアム（サブスク）で使われた回数に応じた分配。**送信されるほど稼げる** |

→ 「買ってもらう」だけでなく「**使ってもらう（送ってもらう）**」ことが売上に直結する。

## 2. 発売前にやること

1. **作る段階で「使える」を最優先**：文字は大きく、感情がひと目でわかる、日常で何度も使う言葉（了解・ありがとう・おつかれ など）
2. **発売日を決めて予告**：審査は早ければ1〜2営業日。承認後は「保留」にして、自分のタイミングで公開できる
3. **公開は火〜金曜が狙い目**という声が多い
4. SNSで「制作過程」を先に見せてファンを作っておく

## 3. 発売日〜1週間（初動）にやること ★最重要

- 各SNSで一斉告知（Instagram / X / TikTok / Threads）
- **友だち・家族に直接LINEで伝える**／プレゼントする（→ すぐ送信してもらえる＝送信数が増える）
- ストーリーズにストアのリンクを貼る（リンクスタンプ）
- 「買ったら使ってみて！」と**使うことまでお願いする**
- プロフィールのリンクをスタンプのストアページにしておく

## 4. SNS別の役割

| SNS | 向いている使い方 |
|---|---|
| **Instagram** | 見た目重視。リールで**メイキング（線画→完成のタイムラプス10秒程度）**、**実際のトーク画面での使用例**、キャラの日常漫画。保存されやすい |
| X（旧Twitter） | 拡散力が一番高い。リポストされやすい告知・漫画 |
| TikTok | 若い層向け。「こんな時に使える」短い動画 |
| LINE（友だち・公式アカウント） | 身近な人へ直接。初動の送信数に効く |

使えるハッシュタグ例：`#LINEスタンプ` `#ラインスタンプ` `#クリエイターズスタンプ` `#LINEスタンプ販売中` ＋ キャラ名の専用タグ

## 5. 長く売れ続けるためにやること

1. **シリーズ化**：同じキャラで第2弾・第3弾。ファンがリピート購入してくれる。1作目だけで判断しない
2. **季節・イベントもの**：年末年始（年賀）、クリスマス、ハロウィン、誕生日など。年末年始は特別企画があり申請期限がある
3. **ターゲットを絞る**：「ママ向け」「敬語」「推し活」など、使う人と場面をはっきりさせる
4. **検索されやすいタイトル・説明文**：使う場面の言葉（敬語・毎日使える 等）を入れる
5. **LINEスタンプ プレミアムを有効に**：使われるほど分配がもらえる
6. **販売実績レポートを見る**：どのスタンプがどれだけ送られているかを確認して次作に活かす

## 4-2. 媒体別の宣伝方法（詳細）

### Instagram（ファンづくり・保存される投稿）

- **プロフィール**：名前にキャラ名＋「LINEスタンプ」を入れる。リンク欄にストアページ（またはスタンプ一覧をまとめたページ）
- **リール**（フォロワー以外に届く）
  - 線画→完成のタイムラプス（10秒前後）
  - 「こんな時に使える」：実際のトーク画面の画面録画でスタンプを送る様子
  - 「〇〇な人あるある」をスタンプで再現
  - 最初の1〜2秒に「え？」と思わせる画面やテロップを入れる
- **カルーセル**：全40個の一覧、シーン別の使い方。保存されやすい
- **ストーリーズ**：発売日のカウントダウン、リンクスタンプでストアへ直接。「どれが好き？」の投票・質問スタンプで反応をもらう
- **ハイライト**：「スタンプ一覧」「新作」「使用例」で常にストアへ行けるようにする
- **ハッシュタグ**：`#LINEスタンプ` などの大きいタグ＋キャラ名の専用タグ。数は多すぎず、内容に合うものに絞る
- **コラボ投稿**：クリエイター仲間と共同投稿で相互のフォロワーに届ける

### X（旧Twitter）（拡散・告知の中心）

- スタンプ専用アカウントを作り、アイコン・名前でキャラとスタンプだとすぐわかるようにする
- **発売告知を固定ポスト**にする（画像＋ストアURL）
- 画像は「スタンプ一覧」より、**一番刺さる1〜4個を大きく**見せる
- キャラの**1〜4コマ漫画**や「あるある」ネタで日常的に投稿 → リポストされやすい
- ハッシュタグ：`#LINEスタンプ` `#クリエイターズスタンプ` `#LINEスタンプ宣伝` など
- スタンプ紹介アカウントや、クリエイター同士の交流タグに参加する
- 告知の時間は夜（19時前後）が良いという声あり

### TikTok（若い層・バズ狙い）

- 「〇〇の時に使えるスタンプ」「彼氏／友達に送ったら…」など**使う場面**を短く見せる
- キャラが動くアニメーション、制作過程を流行りの音源に合わせる
- 説明欄・プロフィールからストアやまとめページへ誘導する

### LINE（初動の送信数を作る）

- 家族・友だちに「発売したよ」と送り、**実際にそのスタンプを使ってもらう**
- スタンプのプレゼント機能で身近な人に贈る（すぐ送信されやすい）
- LINE公式アカウントを作り、新作のお知らせを配信する
- LINE VOOM にも投稿する

### その他

- **LINEスタンプ紹介サイト**に登録する
- **ブログ・note**：制作の裏話や売上報告は読まれやすく、そこからストアへ誘導できる
- **Threads**：Instagramと連携でき、制作の話や雑談で交流しやすい
- **YouTubeショート**：TikTokと同じ動画を使い回せる

### 発売告知のタイミング

- 公開は「火〜金曜」「土日の夕方」など意見が分かれる。自分のフォロワーが一番見ている時間（インサイトで確認）に合わせて公開し、**公開直後に全SNSで一斉告知**するのが基本

### 注意

- 企業の商品宣伝を目的としたスタンプは、クリエイターズスタンプでは販売できない（規約違反）
- 他の人の作品やキャラクター・楽曲の無断使用は避ける

## 6. やりがちな失敗

- 作って申請したら終わり（誰にも見つけてもらえない）
- 絵の上手さばかりにこだわり、トークで使いにくい
- インスタに完成画像を1枚載せるだけ（「どんな場面で使えるか」が伝わらない）
- 1作だけで諦める

## インスタ投稿の構成案

### リール（30〜45秒）

| 秒数 | 画面 | テロップ |
|---|---|---|
| 0–3 | 売上画面 or スタンプ一覧 | 「LINEスタンプ、作って終わりにしてない？」 |
| 3–8 | ランキング画面 | 「売れるカギは**発売1週間**」 |
| 8–18 | 告知・友だちに送る様子 | 「①発売日に全SNSで告知 ②友だちに送って"使って"もらう」 |
| 18–28 | トーク画面での使用例 | 「③"使ってる場面"を動画で見せる」 |
| 28–38 | 第2弾・季節もの | 「④シリーズ化＆季節ものでファンを増やす」 |
| 38–45 | まとめ | 「保存して発売日に見返してね」 |

### カルーセル（保存用・8枚）

1. 表紙「作ったLINEスタンプを売る方法」
2. 売れる仕組み（ランキング＝送信数と初動）
3. 発売前の準備
4. 発売1週間でやること
5. SNS別の使い分け
6. シリーズ化・季節もの
7. やりがちな失敗
8. まとめ＋「保存してね」
