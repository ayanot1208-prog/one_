# Threads 投稿

- 開始：2026-10-24（本人指示：1日5投稿）
- 目的（仮置き）：あやさんの人柄・考え方を知ってもらい、フォロワーを増やす → プロフィール経由でインスタ・LINE（「AIマネタイズの教科書」）へ
- Threadsの特徴に合わせる：
  - 1投稿は短め（数行〜10行程度）
  - 語りかける口調（です・ます調にしすぎない）
  - ハッシュタグは付けない（付けるなら1つ）
- 守ること（既存ルールと同じ）：
  - 事実だけを使う（盛らない）
  - 「毎月100万」とは言わない
  - 下手に出る言葉（ありがとうございます、よろしくお願いします等）は使わない
  - 「500円の案件」ではなく「時給換算500円」

## 1日5投稿の型

| 枠 | 時間の目安 | 役割 | 中身 |
|---|---|---|---|
| ① | 朝 7〜8時 | マインド | 行動を後押しする短い気づき。ONE MINDSETやあやさんの体験から |
| ② | 昼 12時 | AI活用 | すぐ真似できる具体的なTips（保存されやすい）。導線を入れるならここ |
| ③ | 夕方 18時 | 過去〜今のストーリー | AD時代・時給換算500円・月収100万までの事実 |
| ④ | 夜 21時 | 本音・裏側 | キラキラして見える部分の裏側。親近感 |
| ⑤ | 夜 22〜23時 | 問いかけ | 選択肢や質問でコメントをもらう（次の投稿ネタにもなる） |

## Day1（2026-10-24 作成）

### ① 朝・マインド

### ② 昼・AI活用
```
AIで作業時間を減らしたいなら、
最初にやるのは「自分の仕事を書き出すこと」。

・毎日やってること
・毎回同じ手順でやってること
・時間はかかるのに、頭は使ってないこと

この3つに当てはまる作業から、AIに任せていく。

私は今年の3月からClaude Codeを使い始めて、
自分の手でやってた作業をどんどん任せるようになった。
空いた時間で、新しい仕事も受けられるようになったよ。

AIの始め方は、プロフィールのリンクから
「AIマネタイズの教科書」で無料で受け取れます。
```

### ③ 夕方・ストーリー
```
1年ちょっと前の私

・テレビ番組のADで、手取り18万
・徹夜が当たり前
・どれだけ働いても給料は上がらない

フリーランスになってからも、
朝6時から夜中まで編集して
時給にしたら500円くらいの時期があった。

そこからAIで働き方を変えて、
先月、初めて月収100万円を超えた。

変わったのは才能じゃなくて、働き方。
```

### ④ 夜・本音
```
「フリーランスって自由でいいね」って言われるけど、
最初の頃は全然自由じゃなかった。

案件を取りすぎて、朝6時から夜中まで編集。
心も体も、正直限界に近かった。

今、場所も時間も縛られずに働けてるのは
AIに任せられることを任せるようにしたから。

自由って勝手に手に入るものじゃなくて、
仕組みで作るものなんだと思う。
```

### ⑤ 夜・問いかけ
```
AIで在宅ワークを始めてみたい人に聞きたい。

いちばん不安なのはどれ？

① 何から始めればいいか分からない
② パソコンやAIが苦手
③ 時間がない
④ 怪しい情報が多くて、誰を信じていいか分からない

番号だけでもいいので、コメントで教えて。
```

> メモ：
