## 1.5 現在のセールス方向性（重要・2026-09-07決定）

②のピラーを使って、以下の型で売っていく方針が固まった。単発ネタではなく**一連のストーリー（シリーズ）**
として設計する。

- **ターゲット（絞り込み）**: フリーランスとして活動しているが、案件を獲得できていない人
- **訴求の型（オリジンストーリー型セールス）**: 「私も昔は同じ状況だった → ある環境に身を置いて変われた
  → だからあなたも仲間になりませんか」という構成で、読み手に **「私も仲間になりたい」** と思わせる

### ストーリーの型（6ステップ）

1. **会社員時代の違和感・閉塞感**（共感フック）→ なぜフリーランスになろうと思ったのか
2. **会社を辞めた理由・決断の瞬間**（覚悟が伝わるエピソード）
3. **フリーランスになったものの案件が取れず苦しんだ時期**（ターゲットの「今」と重なる部分）
4. **転機**：ある環境・コミュニティ・学びに出会った
5. **その環境での変化**（Before/After、具体的な数字や心境の変化）
6. **誘い**：「今、一緒に頑張る仲間を募集している」→ LINE OCへの導線

> 1・2番目のネタ（なぜフリーランスになったか／なぜ会社を辞めたか）はこのシリーズの**序盤パーツ**として使う。
> 単体で消費させず、「③苦しんだ時期」「④転機」「⑤変化」「⑥誘い」まで続けて初めて効果が出る構成なので、
> 続きのネタが出てきたらこのシリーズの何話目かを意識してネタ帳に記録していく。
> Stories：1テーマずつハイライト化して連続視聴を促す／LINE OC：登録者に向けてより深く・長めに語る。

## 2. Stories と LINE オープンチャットの使い分け

bioの導線上、LINE OCは単なる交流の場ではなく「登録後の見込み客と関係を作り、最終的にサービスへつなげる場」。
Storiesは母集団（フォロワー）に対して人柄を見せ、LINE登録への興味を作る役割。

| | Instagramストーリーズ | LINEオープンチャット |
|---|---|---|
| 役割 | 母集団への人柄開示・興味喚起 | 登録者との関係構築・教育・信頼構築 |
| 特性 | 24時間で消える、気軽、リアルタイム感 | 蓄積される、クローズドで濃い、双方向会話がしやすい |
| 向いている内容 | 日常のひとコマ、感情、即時性のあるネタ、投票/質問スタンプ | じっくり語る系の話、ノウハウの裏側、コミュニティ限定の本音 |
| トーン | ラフ、素の自分 | やや丁寧だが本音ベース、"ここだけの話"感 |
| 使い方の型 | 1テーマ1〜3枚で完結、スタンプで反応を取る | 長文OK、背景・経緯まで含めて語る、コメントで対話 |

## 3. よく使えるフォーマット（型）

- **朝/夜のひとこと日記**: 「今日は〇〇でした」+ 一言の気づき
- **Before/After**: 昔の自分 → 今の自分（考え方・状況の変化）
- **失敗談 → 学び**: 具体的な失敗 → そこから得た教訓
- **Q&A**: フォロワーからの質問に答える（Storiesの質問スタンプ活用）
- **今日の学び**: 仕事や読書、会話から得た気づきを一言で
- **裏側シリーズ**: 投稿の裏側、意思決定の裏側、チームの様子
- **価値観の言語化**: 「私が大事にしていること」を具体エピソードとセットで
- **リアルタイム実況**: 今やっていること、今考えていることをそのまま

## 5. 運用メモ

- ネタを受け取ったら: ①カテゴリ分類 → ②Stories/LINE OCどちらに向くか判定 → ③具体的な発信案（キャプション/構成）を提案
- 定期的にこの表を見返して、ピラーごとの偏りがないかチェックする（①⑤⑥が少なければ日常ネタを意識的に集める、など）
- 「使用済」にしたネタも消さずに残す（後で似た切り口で再利用できるため）
