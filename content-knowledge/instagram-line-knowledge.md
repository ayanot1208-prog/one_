# Instagramストーリーズ / LINEオープンチャット 発信ナレッジ

対象アカウント: [@aya_sns_ai_](https://www.instagram.com/aya_sns_ai_)
目的: パーソナルな部分（人柄・価値観・日常・仕事の裏側）を発信し、フォロワーとの距離を縮める。
運用方法: 思いついたことをそのまま送ってもらい、下の「ネタ帳」に蓄積 → カテゴリ分け・発信案を一緒に考える。

---

## 1. 発信の軸（コンテンツピラー）

パーソナルブランディングでは「専門性」と「人柄」の両方が必要。アカウント名に "sns_ai" とある通り、
SNS運用・AI活用の専門性はすでに強み。ここでは特に**人柄が伝わる面**を強化するために、以下の軸で
ネタをストックしていく。

| ピラー | 内容の方向性 | 主な発信先 |
|---|---|---|
| ① 日常・プライベート | 何気ない日常、休日の過ごし方、趣味、ちょっとした感情の動き | Stories中心 |
| ② 仕事の裏側 | チーム運営、意思決定の裏側、失敗と学び、経営者としてのリアル | Stories / LINE OC |
| ③ 知見・気づき（SNS×AI） | AI活用Tips、SNS運用で学んだこと、業界の変化への所感 | LINE OC中心 |
| ④ 価値観・想い | なぜこの仕事をしているか、大事にしていること、原体験 | Stories / LINE OC |
| ⑤ 本音・弱さ | 悩み、迷い、失敗談、完璧じゃない部分 | Stories中心（親近感） |
| ⑥ フォロワーとの交流 | 質問箱、アンケート、コメント返信、雑談ネタ | Stories（双方向機能活用） |

> ポイント: ①⑤⑥は「親しみやすさ」、②③④は「信頼・専門性」を作る。両方をバランスよく混ぜる。

## 2. Stories と LINE オープンチャットの使い分け

| | Instagramストーリーズ | LINEオープンチャット |
|---|---|---|
| 特性 | 24時間で消える、気軽、リアルタイム感 | 蓄積される、クローズドで濃い、双方向会話がしやすい |
| 向いている内容 | 日常のひとコマ、感情、即時性のあるネタ、投票/質問スタンプ | じっくり語る系の話、ノウハウ、コミュニティ限定の本音 |
| トーン | ラフ、素の自分 | やや丁寧だが本音ベース、"ここだけの話"感 |
| 使い方の型 | 1テーマ1〜3枚で完結、スタンプで反応を取る | 長文OK、背景・経緯まで含めて語る、コメントで対話 |

---

## 3. よく使えるフォーマット（型）

- **朝/夜のひとこと日記**: 「今日は〇〇でした」+ 一言の気づき
- **Before/After**: 昔の自分 → 今の自分（考え方・状況の変化）
- **失敗談 → 学び**: 具体的な失敗 → そこから得た教訓
- **Q&A**: フォロワーからの質問に答える（Storiesの質問スタンプ活用）
- **今日の学び**: 仕事や読書、会話から得た気づきを一言で
- **裏側シリーズ**: 投稿の裏側、意思決定の裏側、チームの様子
- **価値観の言語化**: 「私が大事にしていること」を具体エピソードとセットで
- **リアルタイム実況**: 今やっていること、今考えていることをそのまま

## 5. 運用メモ

- ネタを受け取ったら: ①カテゴリ分類 → ②Stories/LINE OCどちらに向くか判定 → ③具体的な発信案（キャプション/構成）を提案
- 定期的にこの表を見返して、ピラーごとの偏りがないかチェックする（①⑤⑥が少なければ日常ネタを意識的に集める、など）
- 「使用済」にしたネタも消さずに残す（後で似た切り口で再利用できるため）
