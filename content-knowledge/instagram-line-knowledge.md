## 1.5 現在のセールス方向性（重要・2026-09-07決定）

②のピラーを使って、以下の型で売っていく方針が固まった。単発ネタではなく**一連のストーリー（シリーズ）**
として設計する。

- **ターゲット（絞り込み）**: フリーランスとして活動しているが、案件を獲得できていない人 /
  案件はあるが力技（長時間労働）で消耗しているフリーランス（★実際のエピソードにより後者に寄っている、下記参照）
- **訴求の型（オリジンストーリー型セールス）**: 「私も昔は同じ状況だった → ある環境に身を置いて変われた
  → だからあなたも仲間になりませんか」という構成で、読み手に **「私も仲間になりたい」** と思わせる

### ストーリーの型（6ステップ・2026-09-07 実話に合わせて修正）

1. **会社員時代の違和感・閉塞感**（共感フック）→ なぜフリーランスになろうと思ったのか
2. **会社を辞めた理由・決断の瞬間**（覚悟が伝わるエピソード）
3. **がむしゃらに働きすぎて苦しんだ時期**（当初想定は「案件が取れない」だったが、実話は逆で
   「案件が取れすぎてリソースパンク、朝6時〜夜24時の力技」だった。"取れない"苦しさではなく
   "捌ききれない"苦しさとして描く。長時間労働で消耗しているフリーランス層に刺さる）
4. **転機**：2026年3月、Claude Codeとの出会い。仕事をAIに任せられるようになり、
   自分の手が空いた分さらに他の仕事を受けられるように（判明済み・エピソード6参照）
5. **その環境での変化**：労働時間（朝6時〜夜24時→昼12時〜夜24時）、頑張りが正当に評価され収入も
   上がるようになったこと、そして生まれた時間で"この発信"を始めたこと（判明済み・エピソード7参照）
6. **誘い**：フリーランスで同じように悩んでいる人に、少しでも前に進めるようになってほしい、
   という動機からLINE OCへ誘導（判明済み・エピソード8参照）

> ★2026-09-07時点で1〜6全てのステップの素材が揃い、シリーズの骨子は完成。エピソード1〜8として
> Stories/LINE OC台本もドラフト済み。あとは実際の投稿順・投稿頻度を決めて出していくフェーズ。
> Stories：1テーマずつハイライト化して連続視聴を促す／LINE OC：登録者に向けてより深く・長めに語る。

## 2. Stories と LINE オープンチャットの使い分け

bioの導線上、LINE OCは単なる交流の場ではなく「登録後の見込み客と関係を作り、最終的にサービスへつなげる場」。
Storiesは母集団（フォロワー）に対して人柄を見せ、LINE登録への興味を作る役割。

| | Instagramストーリーズ | LINEオープンチャット |
|---|---|---|
| 役割 | 母集団への人柄開示・興味喚起 | 登録者との関係構築・教育・信頼構築 |
| 特性 | 24時間で消える、気軽、リアルタイム感 | 蓄積される、クローズドで濃い、双方向会話がしやすい |
| 向いている内容 | 日常のひとコマ、感情、即時性のあるネタ、投票/質問スタンプ | じっくり語る系の話、ノウハウの裏側、コミュニティ限定の本音 |
| トーン | ラフ、素の自分 | やや丁寧だが本音ベース、"ここだけの話"感 |
| 使い方の型 | 1テーマ1〜3枚で完結、スタンプで反応を取る | 長文OK、背景・経緯まで含めて語る、コメントで対話 |

### LINE OCの文体ルール（★2026-09-08追加・重要）

あやさんの希望：LINE OCの投稿は、1つの長文メッセージとしてまとめて送るのではなく、**1〜2行程度の
短い吹き出しを何通も連続で送る「雑談っぽい」チャット形式**にしたい。

参考例：かず氏（ONEの運営メンバー間LINEグループ）の発言スタイル。1メッセージが数秒〜1分間隔で
短く連投される様子：

```
オプチャマーケはめちゃ能力値問われるな

まだオプチャうまいなと思える人は全然いない

でいうと僕とゆうと君のみかな、その能力があると思えるのは

尾崎くん、豊岡さんでギリ

オプチャを極められる人からインスタも爆売れすると思う圧倒的に

大事なのは常に「why」

なんで自分はこの発信をしているのか

なんで今この時代にAIを学ぶべきなのか

フリー戦略は7年前から伝えてる通り、

2割のWhat、Howに対して

8割のWhy

を伝える

これ

そもそも人はWhyの問いに対して深く答えを持っている人が賢いと思うし

その抽象化能力こそこの発信者で埋もれる時代の競合優位性になる

逆にWhatとかHowで差別化するのはまぁまず無理。すぐパクられるし
```

→ 今後、LINE OC向けの投稿案を作成する際は、**1つの長文ブロックではなく、上記のように短文を
複数メッセージに分けた台本形式（1吹き出し＝1〜2行）で提案する**こと。内容がじっくり語る系でも、
配信時は短文の連投で臨場感・雑談感を出す。

## 3. よく使えるフォーマット（型）

- **朝/夜のひとこと日記**: 「今日は〇〇でした」+ 一言の気づき
- **Before/After**: 昔の自分 → 今の自分（考え方・状況の変化）
- **失敗談 → 学び**: 具体的な失敗 → そこから得た教訓
- **Q&A**: フォロワーからの質問に答える（Storiesの質問スタンプ活用）
- **今日の学び**: 仕事や読書、会話から得た気づきを一言で
- **裏側シリーズ**: 投稿の裏側、意思決定の裏側、チームの様子
- **価値観の言語化**: 「私が大事にしていること」を具体エピソードとセットで
- **リアルタイム実況**: 今やっていること、今考えていることをそのまま

### 自己振り返り（2026-09-09セッションの反省・次回への申し送り）

- **文言修正は「語感」だけでなく「論理」も毎回読み直す。** 語尾の重複を解消しようとして「て」→「ので」に
  変えた結果、直後の「そういえば」（想起）と噛み合わなくなり、あやさんに「文章繋がってないですよね？」と
  指摘されるまで気づけなかった。表現を調整したら、その一文だけでなく前後のつながりまで音読するつもりで
  確認してから提示する。
- **チャットでの台本提示は実際の改行を使い、「／」等の記号で区切らない。** スラッシュ区切りは省スペースには
  なるが読みにくく、あやさんから「/は削除してください」と明確に指摘された。以後は複数行の引用は必ず
  コードブロック等で実際の改行のまま見せる。
- **画像化（PNGレンダリング）は明示的に「画像で」「送って」と言われた時、または最終稿が固まった段階に
  限定する。** 文言をまだ調整中の段階で毎回画像を作り直すのはコストが高く、実際このセッションでも一度
  画像を送った後は最後まで「文章を送って」で進み、画像の再送は不要だった。イテレーション中はテキスト
  ベースで素早く回すことを優先する。
- **あやさんはドラフトをそのまま使わず、Instagramの編集画面で内容を大きく作り変えてから投稿する。**
  「私について」シリーズでは「2年前」→「1年前」への変更、AD時代の具体的な手取り額（18万円）の追加、
  スライド構成の作り替えなど、ドラフトと最終投稿の間にかなりの差があった。ドラフトは「たたき台」であり
  最終稿ではないと認識し、投稿が完了したタイミングで必ず実際の投稿内容を確認・記録し、「ドラフト版」と
  「公開済み最終版」を知識ファイル内で明確に分けて残す（今回この運用パターンを確立できたので、今後も
  同様の投稿シリーズで継続する）。
- **構成変更（スライドの差し替え・独立化・枚数変更）を行うときは、影響範囲を grep で洗い出してから
  更新する。** 見出しの「◯枚」表記、本文中の「①◯枚目の〜」のような相互参照、注記欄の枚数言及など、
  複数箇所に散らばりやすい。7枚→8枚への拡張時など、更新漏れがないか都度確認する習慣を継続する。
- **保留にした要素（移設先未定の内容など）は、その場でファイルに保留状態を明記し、次の指示で必ず
  解消する。** 今回は「自己投資」の内容を3枚目から一時保留にした際にきちんと注記でき、次のユーザー
  指示（4枚目に独立させる）で解消できた。保留が長引くケースでは見落とすリスクがあるため、次に類似の
  状況が起きた際も同じように明示的な保留メモを残すこと。
