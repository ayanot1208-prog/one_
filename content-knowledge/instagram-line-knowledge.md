## 1.5 現在のセールス方向性（重要・2026-09-07決定）

②のピラーを使って、以下の型で売っていく方針が固まった。単発ネタではなく**一連のストーリー（シリーズ）**
として設計する。

- **ターゲット（絞り込み）**: フリーランスとして活動しているが、案件を獲得できていない人 /
  案件はあるが力技（長時間労働）で消耗しているフリーランス（★実際のエピソードにより後者に寄っている、下記参照）
- **訴求の型（オリジンストーリー型セールス）**: 「私も昔は同じ状況だった → ある環境に身を置いて変われた
  → だからあなたも仲間になりませんか」という構成で、読み手に **「私も仲間になりたい」** と思わせる

### ストーリーの型（6ステップ・2026-09-07 実話に合わせて修正）

1. **会社員時代の違和感・閉塞感**（共感フック）→ なぜフリーランスになろうと思ったのか
2. **会社を辞めた理由・決断の瞬間**（覚悟が伝わるエピソード）
3. **がむしゃらに働きすぎて苦しんだ時期**（当初想定は「案件が取れない」だったが、実話は逆で
   「案件が取れすぎてリソースパンク、朝6時〜夜24時の力技」だった。"取れない"苦しさではなく
   "捌ききれない"苦しさとして描く。長時間労働で消耗しているフリーランス層に刺さる）
4. **転機**：2026年3月、Claude Codeとの出会い。仕事をAIに任せられるようになり、
   自分の手が空いた分さらに他の仕事を受けられるように（判明済み・エピソード6参照）
5. **その環境での変化**：労働時間（朝6時〜夜24時→昼12時〜夜24時）、頑張りが正当に評価され収入も
   上がるようになったこと、そして生まれた時間で"この発信"を始めたこと（判明済み・エピソード7参照）
6. **誘い**：フリーランスで同じように悩んでいる人に、少しでも前に進めるようになってほしい、
   という動機からLINE OCへ誘導（判明済み・エピソード8参照）

> ★2026-09-07時点で1〜6全てのステップの素材が揃い、シリーズの骨子は完成。エピソード1〜8として
> Stories/LINE OC台本もドラフト済み。あとは実際の投稿順・投稿頻度を決めて出していくフェーズ。
> Stories：1テーマずつハイライト化して連続視聴を促す／LINE OC：登録者に向けてより深く・長めに語る。

  エピソード5「ディレクター昇格」の説得力ある裏付け数字として使える。
- **2025年10〜12月**：さらに安定して伸びていく時期（¥21万→26万円台）。
- **2026年以降**：¥26万〜35万円台で安定的に推移、2026年5月に¥356,588でピーク。
  その後は¥26万〜30万円台で横ばい〜微減。
- **全体の伸び**：2025年7月→2026年5月ピークで約6.4倍（¥55,461→¥356,588）。

### 使える発信フォーマット

1. **「収入公開」単体投稿**：この推移をグラフ化して1枚で見せる（インスタでも鉄板の高反応フォーマット）。
   キャプションで各時期に何があったか（ディレクター昇格、案件拡大など）を添えると説得力が増す。
2. **各エピソードへの数字の埋め込み**：Stories/LINE OCの台本内で「あの頃の月収は5万円台でした」
   「ディレクターになった月、収入は2.5倍になりました」のように具体数字を差し込む。
3. **転機（AI/効率化）との対応付け**：2026年3月にClaude Codeを使い始めたことが判明（下記エピソード6参照）。
   実際のデータでも **2026年2月¥264,563 → 3月¥312,268（前月比+約18%）** と、時期がぴったり一致する。
   ピークの2026年5月¥356,588は転機の2ヶ月後。「AIに任せた分、新しい仕事を受けられるようになった」
   という本人の言葉と数字が一致する、説得力の高いBefore/After素材。
   なお2026年6月以降は¥26万〜30万円台に落ち着いている＝AI活用で"稼ぐ量"より"時間の余裕"を
   優先する働き方にシフトした可能性がある（本人に要確認、もしそうならこれもbioの「場所も時間も
   縛られない自由な働き方」を裏付ける良いエピソードになる）。

## 2. Stories と LINE オープンチャットの使い分け

bioの導線上、LINE OCは単なる交流の場ではなく「登録後の見込み客と関係を作り、最終的にサービスへつなげる場」。
Storiesは母集団（フォロワー）に対して人柄を見せ、LINE登録への興味を作る役割。

| | Instagramストーリーズ | LINEオープンチャット |
|---|---|---|
| 役割 | 母集団への人柄開示・興味喚起 | 登録者との関係構築・教育・信頼構築 |
| 特性 | 24時間で消える、気軽、リアルタイム感 | 蓄積される、クローズドで濃い、双方向会話がしやすい |
| 向いている内容 | 日常のひとコマ、感情、即時性のあるネタ、投票/質問スタンプ | じっくり語る系の話、ノウハウの裏側、コミュニティ限定の本音 |
| トーン | ラフ、素の自分 | やや丁寧だが本音ベース、"ここだけの話"感 |
| 使い方の型 | 1テーマ1〜3枚で完結、スタンプで反応を取る | 長文OK、背景・経緯まで含めて語る、コメントで対話 |

## 3. よく使えるフォーマット（型）

- **朝/夜のひとこと日記**: 「今日は〇〇でした」+ 一言の気づき
- **Before/After**: 昔の自分 → 今の自分（考え方・状況の変化）
- **失敗談 → 学び**: 具体的な失敗 → そこから得た教訓
- **Q&A**: フォロワーからの質問に答える（Storiesの質問スタンプ活用）
- **今日の学び**: 仕事や読書、会話から得た気づきを一言で
- **裏側シリーズ**: 投稿の裏側、意思決定の裏側、チームの様子
- **価値観の言語化**: 「私が大事にしていること」を具体エピソードとセットで
- **リアルタイム実況**: 今やっていること、今考えていることをそのまま

### エピソード3「否定から入ってくる人は断捨離する」全文サマリー（唯一テキスト化済み）

音声文字起こしからの要点（口語の言い回しは整理し、内容はそのまま維持）：

- ビジネスを始めるタイミングでは、ほぼ100%誰かから反対される（友人、配偶者、両親、子供、先輩など）。
  自身も学生時代の親友や父親から強く反対された経験がある。
- こうした否定は「ドリームキラー」と呼ばれ、"あなたのためを思って"という体裁を取るが、実際は
  否定してくる本人がネガティブ・マイナス思考であることが多い。
- 否定してくる人が変わってほしくないのは、相手が変化することで自分との関係性や立ち位置が変わるのが
  怖いから（無意識の感情）。
- 否定的な人間関係を断つ（断捨離する）のは冷たい行為ではなく、自分の可能性を守るための戦略的な判断。
- 誰と時間を過ごすかは、自分の未来をどう選ぶかに等しい。「身の回りの5人の平均年収が自分の年収になる」
  という考え方があり、付き合う人を意図的に選ぶことが人生を変える。
- 結果を出せば、最初に反対していた人も手のひらを返す（本人の父親は当初猛反対していたが、今では
  本人が負担する旅行を楽しんでいる、というエピソードあり）。
- 結論：否定から入ってくる人とは、結果を出すまで距離を置く／話さないと決める。応援してくれる人を
  大切にし、自分の人生をポジティブな循環に入れていく。
