# ワンコインコンサル 事前動画の台本（3本）

- 作成日：2026-10-13
- 送るタイミング：個別相談の日程が確定したあと、3本を同時に送る（★2026-10-13 本人確定。
  順番に届く前提の言い回し「次の動画では」「いよいよ最後」などは、同時に届く前提に直した）
- 目的：面談までに教育をかける（マインドを整えて、熱量を持って当日に来てもらう）
- 長さ：1本あたり2分程度（話す速さ1分300字前後として、本文は約600〜700字）
- 1本目・2本目はONE MINDSETを軸にして、あやさん自身の経験を交える
  - 1本目 ← 58話「自己投資が一番コスパのいい投資である」
  - 2本目 ← 68話「100%準備ができた状態はいつまで経っても来ない」と24話「後悔は行動しなかった事で生まれる」
- 使っている事実（すべて記録済みのもの）：
  - 手取り18万のAD時代
  - スクールへの自己投資（金額は出さない。「私について」で12万を出さなかった方針に合わせた）
  - 編集技術は1週間で学んで、すぐに案件を受注
  - 最初の月の収入は5万円台
  - 2026年9月に月収100万
  - インスタを始めて2ヶ月で4,500人
- 守ること：
  - 収入を約束しない
  - 面談の中で講座の案内はしないので、「この先のサポート」には触れない
  - 「毎月100万」とは言わない
- ★2026-10-13 本人指示：「テーマは〜です」のようにテーマを口に出さない。裏の意図はマインドセットを
  伝えること、表向きはあやさん自身の経験や考え方を話す、という形にする。
  見出しの「」は台本内では言わない“裏テーマ”。

## 1本目（裏テーマ：自己投資が一番コスパのいい投資）

```
こんにちは、あやです！
個別相談のお申し込み、本当にありがとうございます。

当日までに見てほしい短い動画を3本お送りしているので、
1本目から順番に見てくださいね。

まずは、私が会社員だった頃の話をさせてください。

当時はテレビ番組のADをしていて、手取りは18万円。
毎日働くだけで精一杯で、
自分のためにお金を使ったことなんて、ほとんどありませんでした。

そんな私が、フリーランスになると決めたとき、
初めて思い切ってスクールに申し込んだんです。

当時の私にとってはかなりの大金で、
申し込むときは正直、すごく怖かったです。

でも、お金を払ったからこそ
「絶対に稼げるようになる」って腹をくくれて、

1週間で編集を学んで、すぐに案件を取りに行きました。

最初の月の収入は、5万円台。
そこから働き方を変えて、
2026年の9月には、月収100万円を達成できました。

今振り返ると、あのとき払ったお金は
何倍にもなって返ってきたなと思います。

服やモノはいつか使わなくなるけど、
自分の中に身につけたスキルや経験って
誰にも奪われないし、ずっと使えるんですよね。

だから私は、
自分に使うお金が一番コスパがいいと思っています。

今回の500円の個別相談も、
あなたが自分のために使ったお金です。
せっかくの1時間なので、
元を取るつもりで来てくださいね笑

2本目も、このまま続けて見てください！
```

## 2本目（裏テーマ：100%準備できた状態はこない／後悔は行動しなかったことで生まれる）

```
こんにちは、あやです！
2本目の動画です。

私がフリーランスとして動画編集を始めたとき、
まだ編集を学び始めたばかりでした。

でも、1週間である程度学んで、
すぐに案件に応募して、受注したんです。

もしあのとき
「もっと上手くなってから」「自信がついてから」って待っていたら、
たぶん今もまだ、準備をしていたと思います笑

インスタも同じで、
発信したいと思ったその日にアカウントを作って、投稿しました。
始めて2ヶ月で、フォロワーは4,500人になっています。

完璧に準備ができていたわけじゃなくて、
動きながら、足りないところを埋めてきただけなんです。

「もう少し勉強してから」
「お金が貯まってから」
「時間ができてから」

そう思う気持ち、すごく分かります。
でも私の経験だと、
そのタイミングって、待っていても来ないんですよね。

それに、やってみて失敗したことって
あとで笑い話にできるんです。

でも、やらなかったことは
「あのときやっていたら」って、ずっと心に残ってしまう。

私は、あのとき動いて本当によかったと思っています。
動いたから、手取り18万円の毎日から抜け出せました。

今回、個別相談に申し込んだあなたも、
もう一歩を踏み出しています。

その一歩を、ここで止めないでくださいね。

3本目も、このまま見てください！
```

## 3本目（裏テーマ：面談の前と後で変わる／絶対に変わるという気持ちを持ってきてほしい）

```
こんにちは、あやです！
3本目、最後の動画です。

1本目でも少しお話ししましたが、
私はスクールに申し込んだとき、
「お金を払ったからには、絶対に稼げるようになる」って決めていました。

だから学び終わってすぐ営業して、
迷わず案件を取りに行けたんだと思います。

もしあのとき
「何か学べたらいいな」くらいの気持ちだったら、
きっと今の私はいなかったです。

同じ時間を使っても、
「何か教えてもらえたらいいな」と思っているときと、
「ここから絶対に変わる」と決めているときでは、
持ち帰れるものが全然違うんですよね。

なので、当日は
「絶対に変わる」という気持ちで来てもらえたら嬉しいです。

当日は、あなたの今の状況と目標を聞いて、
あなたに合ったAIの活かし方と、
次に何をすればいいかを一緒に考えます。

面談の前と後で、
「何をすればいいか分からない」から
「次にやることがはっきりしている」に変わっていたら、
私も本当に嬉しいです。

そのために、当日までに
この3つだけ考えておいてください。

1つ目、叶えたい目標。
いつまでに、どんな生活をしていたいか。

2つ目、今の状況。
お仕事のことや、1日に使える時間。

3つ目、私に聞きたいこと。

あと、当日はZoomで
カメラとマイクをオンにして参加してくださいね。

私も、本気で向き合います。
当日、お話しできるのを楽しみにしています🌿
```

## メモ

- テーマを口に出さず、あやさんの体験→そこから思うこと→視聴者へのひと言、の順で話す形にした（2026-10-13）。
- 1本目の「浪費・消費・投資の3つに分けられる」という講義っぽい説明は削り、「服やモノはいつか使わなくなるけど」という自分の言葉に置き換えた。
- 2本目の「後悔」パートは、あやさん自身の「やらなかった後悔」ではなく、事実として言える「動いたから抜け出せた」で締めた。本人に「やらなかった後悔」の実体験があれば、そこに差し替えるとさらに刺さる。
- 3本目の「3つ考えておいてほしいこと」は、相談後のメモを廃止した代わりに、当日の1時間を濃くするための事前準備。
