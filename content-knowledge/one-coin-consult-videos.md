# ワンコインコンサル 事前動画の台本（3本）

- 作成日：2026-10-13
- 送るタイミング：個別相談の日程が確定したあと（面談当日までに3本）
- 目的：面談までに教育をかける（マインドを整えて、熱量を持って当日に来てもらう）
- 長さ：1本あたり2分程度（話す速さ1分300字前後として、本文は約600〜700字）
- 1本目・2本目はONE MINDSETを軸にして、あやさん自身の経験を交える
  - 1本目 ← 58話「自己投資が一番コスパのいい投資である」
  - 2本目 ← 68話「100%準備ができた状態はいつまで経っても来ない」と24話「後悔は行動しなかった事で生まれる」
- 使っている事実（すべて記録済みのもの）：
  - 手取り18万のAD時代
  - スクールへの自己投資（金額は出さない。「私について」で12万を出さなかった方針に合わせた）
  - 編集技術は1週間で学んで、すぐに案件を受注
  - 最初の月の収入は5万円台
  - 2026年9月に月収100万
  - インスタを始めて2ヶ月で4,500人
- 守ること：
  - 収入を約束しない
  - 面談の中で講座の案内はしないので、「この先のサポート」には触れない
  - 「毎月100万」とは言わない

## 1本目「自己投資が一番コスパのいい投資」

```
こんにちは、あやです！
個別相談のお申し込み、本当にありがとうございます。

当日までに、短い動画を3本お送りします。
1本目のテーマは
「自己投資が一番コスパのいい投資」です。

お金の使い方って
「浪費」「消費」「投資」の3つに分けられるんですよね。

その中でも、一番リターンが大きいのが
自分に使うお金、つまり自己投資だと思っています。

私は会社員の頃、手取り18万円で
自分に投資したことなんて、ほとんどありませんでした。

フリーランスになると決めたとき、
初めて思い切ってスクールに申し込んだんです。

当時の私にとってはかなりの大金で、
正直、すごく怖かったです。

でも、お金を払ったからこそ
「絶対に稼げるようになる」って腹をくくれて、

1週間で編集を学んで、すぐに案件を取りに行きました。

最初の月の収入は、5万円台。
そこから働き方を変えて、
2026年の9月には、月収100万円を達成できました。

あのとき払ったお金は、
何倍にもなって返ってきたと思っています。

株や貯金は減ることもあるけど、
自分の中に身につけたスキルや経験は
誰にも奪われないし、一生使えるんですよね。

だから、自己投資が一番コスパがいいんです。

今回の500円の個別相談も、立派な自己投資です。
せっかくの1時間なので、
元を取るつもりで来てくださいね笑

次の動画では、
「準備ができてから」と思っている方に向けて話します。
ぜひ見てください！
```

## 2本目「100%準備できた状態はこない／後悔は行動しなかったことで生まれる」

```
こんにちは、あやです！
2本目の動画です。

今日は
「100%準備ができた状態は、いつまで経っても来ない」
という話をします。

「もう少し勉強してから」
「お金が貯まってから」
「時間ができてから」

こんなふうに思ったこと、ありませんか？

私も気持ちはすごく分かります。

でも、私がフリーランスとして動画編集を始めたときは、
1週間で編集をある程度学んで、すぐに案件を受注しました。

もしあのとき
「自信がついてから始めよう」って待っていたら、
今の私はいなかったと思います。

インスタも同じで、
発信したいと思ったその日にアカウントを作って、投稿しました。
始めて2ヶ月で、フォロワーは4,500人になっています。

準備が完璧だったわけじゃなくて、
動きながら、足りないところを埋めてきただけなんです。

それともうひとつ、伝えたいことがあります。

後悔って、
「やって失敗したこと」より
「やらなかったこと」から生まれるんですよね。

やってみて失敗したことは、あとで笑い話にできます。
でも、やらなかったことは
「あのときやっていたら」って、ずっと残ってしまう。

私は動いたから、
手取り18万円の毎日から抜け出せました。

今回、個別相談に申し込んだあなたは、
もう一歩を踏み出しています。

その一歩を、ここで止めないでくださいね。

次の動画では、当日までにやってほしいことをお伝えします！
```

## 3本目「面談の前と後で変わる／絶対に変わるという気持ちを持ってきてほしい」

```
こんにちは、あやです！
いよいよ最後の動画です。

今日は、当日に向けて
ひとつだけお願いがあります。

それは、
「絶対に変わる」という気持ちを持って来てほしい、ということです。

同じ1時間でも、
「何か教えてもらえたらいいな」と思って来る人と、
「ここから絶対に変わる」と決めて来る人では、
持ち帰るものが全然違うんです。

私がスクールに入ったときも、
「お金を払ったからには、絶対に稼げるようになる」って決めていました。

だから終わってすぐ営業して、
迷わず案件を取りに行けたんだと思います。

当日は、あなたの今の状況と目標を聞いて、
あなたに合ったAIの活かし方と、
次に何をすればいいかを一緒に考えます。

面談の前と後で、
「何をすればいいか分からない」状態から
「次にやることがはっきりしている」状態に変わってもらうのが、
私のゴールです。

そのために、当日までに
この3つだけ考えておいてください。

1つ目、叶えたい目標。
いつまでに、どんな生活をしていたいか。

2つ目、今の状況。
お仕事のことや、1日に使える時間。

3つ目、私に聞きたいこと。

あと、当日はZoomで
カメラとマイクをオンにして参加してくださいね。

私も、本気で向き合います。
当日、お話しできるのを楽しみにしています🌿
```

## メモ

- 2本目の「後悔」パートは、あやさん自身の「やらなかった後悔」ではなく、事実として言える「動いたから抜け出せた」で締めた。本人に「やらなかった後悔」の実体験があれば、そこに差し替えるとさらに刺さる。
- 3本目の「3つ考えておいてほしいこと」は、相談後のメモを廃止した代わりに、当日の1時間を濃くするための事前準備。
